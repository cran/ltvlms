# ltvlms 0.1.0

- Initial implementation of Logistic, Gompertz, Richards, and LTVLMS curves.
- Bounded multi-start fitting with Latin hypercube initialization.
- Default LTVLMS `r0` search range and the South Africa regression test aligned
  with the latest manuscript's reported Table 3 parameter scale.
- Standard and manuscript-compatible performance metrics.
- Random and forward-in-time cross-validation.
- South Africa and 63-country UNAIDS-derived prevalence datasets.
- Base R prediction, extraction, printing, and plotting methods.
- Display `Gompertz` and `Richards` with publication-style capitalization in
  comparison-plot legends while retaining lowercase programmatic model names.
- Add ORCID identifiers for Redouane Betrouni, Tewfik Kernane, and Bander
  Hussein to package and citation metadata.
